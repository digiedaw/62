## Overview

**Rank: SSS** — Imperialdramon Fighter Mode **(Tempered)** is the
upgraded form of base [Imperialdramon Fighter Mode](/digimon/imperialdramon-fighter-mode/).
Requires the **Dragon Mode** line to be completed first, plus a
dual-branch quest on **Wormmon + Veemon** sides.

## Requirements 📋

- Lv. 70+ Tamer
- Lv. 60+ **Wormmon**
- Lv. 60+ **Veemon**
- Imperialdramon Dragon Mode progression (complete)

## Quest Progression 🗺️

### Wormmon branch

1. Complete the **Calumon** progression.
2. Defeat **Mammothmon** in **Oil Refinery 2**.
3. Return to **Calumon**.
4. Continue the **Richard** progression.
5. Defeat **SkullSatamon** in **Oil Refinery 1**.
6. Return to **Richard**.

### Veemon branch

1. Complete the **Calumon** progression.
2. Defeat **Knightmon** in **Oil Refinery 3**.
3. Return to **Calumon**.
4. Continue the **Richard** progression.
5. Defeat **SkullSatamon** in **Yokohama Village**.
6. Return to **Richard**.

## Notes

- ⚠️ If the **SkullSatamon** quest does not register, **changing
  channels** can resolve the issue (a known server-side fix).
- See also: [Imperialdramon Fighter Mode](/digimon/imperialdramon-fighter-mode/)
  for the base variant.
