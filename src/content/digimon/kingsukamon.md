## Overview

**Rank: SSS+** — KingSukamon is a Virus / Steel Mutant Digimon, unlocked from
**Sukamon** with a single item.

## Requirements 📋

- Sukamon
- 👑 King's Data Code

## King's Data Code 👑

KingSukamon does **not** use a normal Jogress questline.

Obtain **👑 King's Data Code**, then use it on your **Sukamon** to unlock
**➡️ KingSukamon**.

> The DMW page specifically lists **King's Data Code** as KingSukamon's unlock
> item.

## Important 💡

- 👑 **King's Data Code** = Evolution unlock item.
- 🏇 **Soul of Sukamon** = Riding unlock item.
- Attribute: **Virus**
- Element: **Steel**
- Type: **Mutant Digimon**

## Result ✅

**Sukamon** → ➡️ 👑 **KingSukamon Unlocked**
