## Overview

**Rank: SSS+** — DarknessBagramon is Virus / Pitch Black / Jogress, unlocked from
**DarkKnightmon + Bagramon**.

## Requirements 📋

- DarkKnightmon
- Bagramon
- 15× Evil Crystal
- 50× Code Crown

> 📍 **Evil Crystal** is obtained by clearing **Bagramon's Domain**.

## Evil Crystals 💎

1. Enter **Bagramon's Domain** through **Jijimon** at D-Terminal.
2. Defeat the **DarknessBagramon Raid**.

> 🎁 Each clear rewards **1× Evil Crystal**.

You need **💎 15× Evil Crystal**.

## Craft Unlock Items 🔨

Take **15× Evil Crystal** to **📍 UlforceVeedramon FM — DATS Center** and craft:

**📦 Xros Evolution Item Box [DarknessBagramon]** — the box contains:

- 🔴 Inferium Vicious (B)
- 🟣 Inferium Vicious (D)

Use them to unlock **both** DarknessBagramon sides.

## Code Crowns 👑

You also need **50× Code Crown** — obtainable from **GreenZone (Nightsky)** bosses
and **Bagramon's Domain reward boxes**.

## Important 💡

- **15× Evil Crystal** = Unlock Box.
- **50× Code Crown** are also required.
- The Unlock Box and both Inferium Vicious items are **Character Bound**.
- DarknessBagramon is **Virus / Pitch Black / Jogress**.

## Result ✅

**DarkKnightmon + Bagramon** → ➡️ 🌑 **DarknessBagramon Unlocked**
