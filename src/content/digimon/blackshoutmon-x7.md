## Overview

**Rank: SSS+** — BlackShoutmon X7 is unlocked from **Shoutmon DX** via the
**Corrupted Great Xros** items.

## Requirements 📋

- Shoutmon DX
- Tank Digimon
- GreenZone (EX) clear
- 1× Corrupted Code Crown
- 200T

> 📍 Enter **GreenZone (EX)** through **Jijimon** at **D-Terminal**.

## GreenZone (EX) 🛡️

1. Enter **GreenZone (EX)**.
2. Use **Shoutmon DX** for the dungeon — it receives a massive HP buff inside.
3. Survive and defeat **DarknessBagramon**.

> 🎁 Clear reward: **1× Corrupted Code Crown**.

> ⚠️ This is a **Tank-only solo dungeon**.

## Final Craft 🔨

Take **1× Corrupted Code Crown + 200T** to
**📍 UlforceVeedramon Future Mode NPC — DATS Center** and craft:

**📦 Xros Evolution Item Box [Corrupted]** — the box contains:

- 🔴 Corrupted Great Xros - Alpha
- 🔵 Corrupted Great Xros - Beta

## Important 💡

- You need **Corrupted Great Xros - Alpha + Beta + Code Crown** to unlock
  BlackShoutmon X7.
- GreenZone (EX) does **not** require tickets.
- **Tamer Skills are disabled** inside the dungeon.
- DMW recommends roughly **1.8M+ HP, 30K+ DE and 140% BL** for the dungeon.

## Result ✅

**Shoutmon DX** → ➡️ 🖤 **BlackShoutmon X7 Unlocked**
