## Active and Passive Skill

![Tamer skill diagram](/img/tamers/tamer.png)

- Each tamer has 2 slots for **active skills** and 3 slots for **passive skills**.
- You can change your Tamer whenever you have another one unlocked.
- You can use one Tamer's model and keep another Tamer's passive skills.
- Deleted Tamer Skills can be restored if their duration is still available.
- A single cooldown is applied for both skills when the same type of Tamer Skill and Enhanced Tamer Skill are registered simultaneously.
- You can register up to 2 Enhanced Tamer Skills, individually.
- Enhanced and Ultimate Tamer Skills are removable and free to switch anytime.

> The interactive Tamer browser below is rendered automatically. Add Tamer images to `/public/tamers/<slug>.png` and update the `image` field in `src/data/tamers.json` to display them. Same for skill icons — set `activeSkill.icon` / `passiveSkill.icon` to a path under `/public/`.
