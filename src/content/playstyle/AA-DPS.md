# ⚔️ Auto Attack / AA

This guide provides the recommended accessory progression for each stage of the game. Follow the upgrade path below to avoid wasting resources on temporary equipment.

> AA builds focus primarily on dealing damage through normal attacks.
Your Digimon choice, accessories, Vice and other equipment should eventually be optimized around AA
performance.

---

**Pros**

- Consistent damage
- Easier to play
- Easier deck progression
- Better movement during boss mechanics
- Access to the Guardian Memory Skill for extra survivability

**Cons**

- Requires more optimized gear
- Needs more offensive stats
- Cannot skip mechanics without very high damage


## Core Progression

> Goal: Build a basic accessory set as quickly as possible.

- Starter Digimon (Agumon)
- LordKnightmon X
- Underworld Accessories
- Novice Accessories
- Complete File Island, Glacier, Maze, and Server Continent
- Build Radiant Holy Beast Gear
- Royal : X-Knight Bracelet
- D-Ark Lv.1

### Seals Priority

1. Hit Rate (HT)
2. Attack (AT)
3. Health Point (HP)
4. Critical Rate (CT)
5. Skill (SK)
6. Digi-Soul (DS)

>- Don't invest heavily in temporary accessories.
>- Focus on obtaining the complete set before upgrading.
